# MacTranscribe

Транскрибация встреч на Mac: запись, offline-распознавание (Whisper), диаризация, суммаризация.

**Скачать последнюю версию:** [Releases → Latest](https://github.com/art-ps/mac-transcribe-releases/releases/latest) → `MacTranscribe.dmg`

Установка: перетащить приложение в «Программы», первый запуск — правой кнопкой → «Открыть». Требования: macOS 26+, Apple Silicon.
